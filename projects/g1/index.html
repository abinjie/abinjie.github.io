PROJECT 05 / 机器人系统

G1 人形机器人自主任务系统

把导航、视觉感知、灵巧手抓取和自然语言任务编排接入 G1，验证访客接待与物品递送。

个人项目

项目背景

基于 Unitree G1 EDU、O6 灵巧手和双 RGB-D 相机构建自主机器人系统，采用 GPU 服务器感知推理与机器人 PC2 实时控制的分布式架构。

我的工作

系统部署与通信

完成 Docker 环境部署、局域网通信、GPU 容器配置和多服务健康检查，连接服务器推理与机器人侧控制。

建图、定位与导航

基于 Mid-360、FAST-LIO2 和 ROS 1 搭建导航链路，完成激光建图、栅格地图生成、重定位与基于 TEB 的局部规划，在 G1 实机上验证点到点导航。

视觉抓取与任务编排

集成 D455 / D435i、YOLO、InsightFace 和 AnyGrasp，打通物体检测、6-DoF 抓取位姿估计及灵巧手控制，将导航、感知、语音与抓取封装为可调用技能。

长时程任务控制

通过资源租约、超时控制、停止接口与异常处理约束任务执行，在实机上联调访客接待和物品递送等复合任务。

链路概览

01自然语言任务
02导航与识别
03交互与抓取
04递送与状态反馈

方案示意，用于说明模块关系。

项目结果

在真实 G1 平台上完成导航、感知、交互、抓取与递送的多技能串行执行验证。
